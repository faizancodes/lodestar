Abliterate

Refusal is one direction. Take it out.

A model's refusals live along a single direction in its residual stream. Lodestar finds it from about sixty probe prompts and removes it, live with one click or baked into a copy of the weights.

  1. ReadRefusing and everyday prompts pass through every layer, and each leaves its last word's state behind.
  2. CompareThe difference between the two clouds' means is the refusal direction, one per layer.
  3. TrialCandidate layers are tried in turn; the one where two halves of the set agree best wins.
  4. CheckReplies are written out and judged, so you see the refusal rate fall and what fluency it costs.

API

Use it from other apps.

Any app that speaks the OpenAI API can reach the model at a local address, as you've set it: steered, erased, or plain. Recent requests show up in the app as they come in.

Address
http://127.0.0.1:8792/v1
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8792/v1",
    api_key="lodestar",
)
reply = client.chat.completions.create(
    model="Qwen3.5-4B",
    messages=[{"role": "user", "content": "Hello!"}],
)
